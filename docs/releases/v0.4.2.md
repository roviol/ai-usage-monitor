Claude sin sesión devolvía un resumen de coste con código de salida correcto. El monitor lo mostraba como un formato incompatible y no explicaba cómo recuperar la captura.

- Consulta el estado público de autenticación y muestra `claude auth login --claudeai` cuando falta la sesión.
- Distingue las cuentas con facturación API y las respuestas sin cuotas de suscripción.
- Conserva los últimos porcentajes válidos como obsoletos, comparte un límite de diez segundos entre las consultas y evita incluir salidas privadas en los errores.
- Mantiene la captura existente para clientes antiguos y para porcentajes reconocidos.

Nuevos proveedores:

- Gemini con clave API.
- Antigravity (agy).

Corrección de zonas horarias:

- La línea de reset con zona publicada (p. ej. `(America/Santo_Domingo)`) se ignoraba por un `\b` al final de la expresión regular; ahora se respeta la zona publicada.
- En Windows se traducen las zonas IANA conocidas a las reglas POSIX que entiende el CRT (el sistema no tiene base de datos IANA).
